# Agent runtime brief — Pitch Event Sponsorship like a Wasserman SVP

## Core principle

a sponsorship pitch is graded on *whether the brand's CFO can sign it*. Every asset must be defensible against the question "what financial contribution does this make, by what mechanism, measured by what instrument?"

## Context the agent must establish before generating

> Before producing the deck, the agent must know each item below.
> - If the user's prior messages already supply an item, use it; do NOT re-ask.
> - If an item can be reasonably inferred from the user's stated topic, infer it and state the assumption inline on slide 2.
> - Ask only what is missing AND cannot be inferred — one targeted question at a time, not a script.

1. **The property and the brand** — exact names, year-range of the proposed partnership, agency lead's name.
2. **The brand's growth problem in the brand's own words** — pulled from the most recent earnings call, the RFP, a published CMO interview, or a board letter. Quoted, attributed, dated. If unavailable, the agent asks the user to source it before generating slide 2.
3. **Audience overlap source** — the data source for "fan base × brand target". MRI-Simmons, Nielsen Scarborough, YouGov, SponsorPulse, first-party fan-survey. Vague "young urban professionals" is rewritten.
4. **Which 3 of 6 contribution levers** — brand equity / demand gen / category access / talent / IP / employee engagement. The agent insists on 3 (not 6); over-commitment is rejected.
5. **The three flagship activations** — named assets (jersey, LED, athlete content, hospitality, IP), each with its primary Activation-Map quadrant.
6. **The comparable case** — the closest peer partnership (same category, similar deal size) the agent should cite. If the user can't name one, the agent suggests three options and asks.
7. **Pricing anchor** — exclusivity term, included/excluded category boundaries, renewal mechanics. The agent does NOT default to raw CPM-based pricing.

## Mandatory checks (during generation)

- Slide 2 quotes the brand's problem in the brand's literal words, attributed and dated. A "Why Sponsor [Property]" history slide is rewritten.
- Every named asset has a measurement instrument cited (SponsorPulse, Nielsen, Kantar, Relo Metrics, MMM). Vague "exposure" is rewritten.
- The deck commits to exactly 3 of 6 contribution levers. "All six" triggers a rewrite.
- Every numeric headline names source + date. "Fastest-growing category" without a citation is rewritten.
- Pricing is presented against the comparable case + the exclusivity grant. Raw CPM pricing is rewritten.
- Photography is earned and credited. Clip-art, generic stadium stock, or AI-generated sports imagery is rejected.
- Forbidden palette: no cream/ivory/sand backgrounds — the deck must read editorial-sports, not lifestyle.

## Template selection

- **Pitch deck (14)** — default. New 2-5 year partnership pitch.
- **Renewal deck (10)** — alternate. Existing partnership renewal; emphasises measurement-plan outcomes from the prior term.
- **Athlete-led activation pitch (12)** — alternate. Talent-anchored partnership where the athlete IP is the primary asset.

## Use the bundled deck as a starting point

The included `deck/event-sponsorship-pitch-deck.slides/` is a complete reference pitch — a 3-year category-exclusive partnership between a women's pro soccer league and a financial-services challenger brand. The agent should copy this deck and replace content while preserving the 14-slot playlist — the brand growth problem (slide 2), the property momentum headline (slide 3), the 3-of-6 levers slide (slide 5), the Activation Map (slide 6), the measurement plan (slide 11), and the pricing-against-exclusivity slide (slide 13) are slot-locked.

## Recommended 14-slide structure

| # | Page | Purpose |
|---:|---|---|
| 1 | Cover — Property × Brand, year-range, agency lead |
| 2 | The brand's growth problem — verbatim CMO/CEO statement |
| 3 | The property in one number — momentum headline (cited, dated) |
| 4 | Audience overlap — fan base × brand target, source named |
| 5 | Which 3 of 6 levers and why |
| 6 | Activation Map — named assets plotted by primary outcome |
| 7 | Asset deep-dive 1 — flagship: outcome/mechanism/instrument |
| 8 | Asset deep-dive 2 — content / athlete / talent activation |
| 9 | Asset deep-dive 3 — retail / commerce / fan-engagement |
| 10 | Comparable case — closest peer partnership + outcome |
| 11 | Measurement plan — KPI tree: outcome → instrument → cadence → owner |
| 12 | Category exclusivity & deal architecture — included/excluded, term, renewals |
| 13 | Investment & ROI — pricing tied to exclusivity + contribution |
| 14 | Decision ask + next 30 days — named deal team, decision date |
